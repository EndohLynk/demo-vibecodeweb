# demo-vibecodeweb

Trang giới thiệu bản thân cơ bản của **Endoh Lynk**.

## Chạy local

Mở `index.html` trong trình duyệt, hoặc từ thư mục dự án:

```bash
python -m http.server 8000
```

Rồi vào [http://localhost:8000](http://localhost:8000).
